# Manoj Reddy — Personal Portfolio

A custom-built, responsive, single-page portfolio website. No framework or build step required.

## Preview locally

Open `index.html` in a browser, or from this folder run:

```bash
python -m http.server 8080
```

Then visit http://localhost:8080.

## Deploy for free with GitHub Pages

1. Create a new **public** GitHub repository named `manoj-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root (you may include this README).
3. Open **Settings → Pages → Build and deployment**.
4. Set **Source: Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. Your site will be at `https://manojreddydev.github.io/manoj-portfolio/` after GitHub Pages finishes deploying.

Alternatively, for a username site, create a repository named `manojreddydev.github.io` and follow the same steps.

## Customisation

- Contact details and project links are in `index.html`.
- Colors and typography are at the top of `styles.css` (`:root`).
- Scroll reveals, navigation and the interactive orbit are in `script.js`.
- The project screenshots load directly from the two public GitHub repositories. The design has text fallbacks if a screenshot is unavailable.
- This portfolio intentionally describes ProcureFlow and Customer360 as **local fictional/synthetic-data prototypes**, not live production deployments.
- No analytics, tracking cookies or third-party JS dependencies. Fonts are fetched from Google Fonts when online, with local fallbacks.
- Motion is disabled for visitors who prefer reduced motion. Keyboard focus and semantic landmarks are included.
